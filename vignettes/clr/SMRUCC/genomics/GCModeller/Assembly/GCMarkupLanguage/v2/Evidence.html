Evidence

Description

虚拟细胞模型之中的文献证据索引。

模型之中的基因、蛋白质、反应以及调控关系都通过文献的编号来引用本表之中的记录， 从而达到“数据可溯源”的目的。为了控制模型文件的体积，本表不保存文献的正文内容。

Declare

            
# namespace SMRUCC.genomics.GCModeller.Assembly.GCMarkupLanguage.v2
export class Evidence {
   authors: string;
   doi: string;
   # 证据的类型：实验证据(exp)、计算证据(comp)或者推断(inf)
   evidenceType: string;
   # 文献在本模型之中的唯一编号，通常为BioCyc数据库的 PUB-xxxx 编号
   id: string;
   pubmed: string;
   source: string;
   title: string;
   year: integer;
}
