Compartment

Description

虚拟细胞模型之中的区室定义。

虚拟细胞模型的反应方程以及化合物的定位所使用的区室编号必须在本表之中存在， 这样可以保证模型文件本身是自描述的，而不需要依赖外部的区室映射表。

   id: string;
   # 区室的离子强度，单位：mol/L
   ionicStrength: double;
   kind: CompartmentKind;
   # 区室所相邻的膜结构编号
   membrane: string;
   name: string;
   # 区室的pH值
   pH: double;
   # 区室的体积，单位：飞升(fL)
   volume: double;
}
