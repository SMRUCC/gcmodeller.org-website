FEATURES

Description

GenBank记录之中的FEATURES段: 位点注释数据的列表。

这里的索引(按照类型分组索引以及位置区间索引)全部是惰性构建的: 当列表被修改的时候，索引会被标记为失效，在下一次查询的时候才会重新构建。 由于读取大型数据库文件的时候一般只会进行查询操作，因此这种方式不会带来额外的初始化开销。
