FeatureIntervalIndex

Description

feature 的位置区间索引。

索引内部按照位点的起始位置进行排序，并且预先计算了"前缀最大结束位置"， 从而可以将FEATURES.GetByLocation()的线性扫描查询(O(n)) 优化为区间树的二分查询(O(log n + k))。
